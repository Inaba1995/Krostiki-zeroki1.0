# Крестики-нолики 1.0

Консольная игра в крестики-нолики на Python.

## Цель проекта
Реализовать классическую игру с ИИ-противником.

## Задачи
- Создать игровое поле
- Реализовать логику победы/поражения
- Добавить противника-компьютер

## Результат
Консольная игра, где можно играть против компьютера или второго игрока.

## Стек технологий
- Python

## Запуск
```bash
python main.py
```
